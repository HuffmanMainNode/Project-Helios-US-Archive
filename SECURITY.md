# Security Policy

## Supported Versions

Only the `main` branch is currently supported for security-related fixes.

## Reporting a Vulnerability

Please do not publish exploit details, credentials, personal data, or sensitive proof-of-concept material in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability**.

The availability of private vulnerability reporting has not been verified in this repository's settings. If that option is unavailable, contact the maintainer through the public [HuffmanMainNode GitHub profile](https://github.com/HuffmanMainNode) and request a private reporting channel. Do not transmit sensitive technical details until a secure channel has been confirmed.

Please include the affected path or version, impact, and safe reproduction steps when a private channel is available. A report is not confirmation that a vulnerability exists. No response-time commitment is promised.
